# 自定义 JS 音源

入口：设置 → 账号与内容 → 自定义音源。支持从本地 UTF-8 `.js` 文件或 HTTP(S) 链接导入，初始化成功才保存并启用；支持多个音源的启停、排序、删除和重新检查。检查脚本只验证初始化，不代表上游服务一定能返回可播放的歌曲。

链接导入会下载一份脚本到本地，支持 HTTP 重定向，下载超时为十二秒、最大 1 MB；不把导入链接写入音源配置或日志，不附带应用账号 Cookie，不自动订阅更新。链接必须直接返回 JS 文件，网页、JSON、空响应或过大文件会显示错误并允许修改后重试。下载和初始化期间可以取消；失败不会修改已有音源列表。文件和链接共用 UTF-8 解码、脚本初始化、去重及保存流程。

## 播放规则

1. 本地文件优先；在线歌曲先请求网易云。
2. 网易云返回空 URL、试听标记，或 URL 响应时长不超过 30,000 ms 时，进入 JS 音源。
3. 按列表顺序每隔 150 ms 启动一个脚本，最多同时运行三个。首个通过完整音频校验的结果胜出，其余任务取消；JS 阶段总等待上限为 18 秒。
4. 单个脚本根据声明的平台获取候选歌曲。网易云 `wy` 使用原 ID；`tx`、`kw`、`kg`、`mg` 分别搜索 QQ、酷我、酷狗、咪咕并核对歌名、歌手和时长。QQ 的 songmid 与数字 songId、酷狗各音质 hash 分开适配。
5. 按用户选择的音质尝试脚本声明的档位，允许向下尝试，不向上提升。播放器显示来源和选中的源音质档位；脚本只返回 URL，不能保证其音质声明真实。
6. JS 阶段无结果时直接返回无可用音源，沿用播放队列的失败处理。旧解灰自动回退暂时禁用，保留实现以便后续单独调试；播放链路不会调用旧解灰解析器。
7. 实际播放发生来源错误时，网易云先刷新一次 URL；之后暂时排除坏的脚本/平台/歌曲/音质组合，重新尝试其他结果。每首歌最多恢复六次，排除记录五分钟后过期。无结果时沿用播放队列的跳过策略。

网易云使用 URL 接口返回的毫秒时长；缺失该字段时探测音频。JS 结果使用 Media3 提取器、限量 HTTP Range 请求探测，最多读取 2 MB、最多探测八秒。无法确认音频时长、非音频响应、短试听和明显错版结果会被拒绝；HLS 等无法通过此探测的结果目前不会采用。

完整音频使用独立缓存命名空间，历史试听缓存不会直接复用。不同脚本、平台歌曲和音质不会共用音频缓存键；更改脚本启用或排序会使短期 URL 缓存失效。过渡分析的预解析不会覆盖播放错误恢复所依据的来源。

## 兼容范围和资源限制

基线为 [LX 移动端自定义源协议](https://lxmusic.toside.cn/mobile/custom-source)，使用 QuickJS-KT 1.0.14。宿主包括：

- `globalThis.lx`、`env=mobile`、API `version=2.0.0`、脚本元信息、`inited` / `request` / `updateAlert` 事件。
- `musicUrl`、Promise、`lx.request` 回调、HTTP 取消（返回值可直接调用，也支持 `.abort()`）。
- HTTP method、headers、body、form、普通文本 formData、timeout；JSON Content-Type 自动解析。
- `setTimeout` / `clearTimeout`、Buffer 的 UTF-8 / hex / Base64 转换、MD5、随机字节、AES-128-CBC/ECB 和 RSA 无填充公钥加密。

每次解析使用独立的脚本上下文，32 MB JS 堆、512 KB 栈、单次执行两秒、整个上下文十五秒。HTTP 响应最多 2 MB、请求最长十秒、单脚本最多十六个并发 HTTP 请求。用户脚本保存在应用不备份目录，不打包社区音源。

脚本没有 Java 反射、Node `require`、文件系统或应用 Cookie 访问接口；HTTP 客户端独立且不注入账号凭据。脚本仍可自行访问网络，应仅导入可信文件。QuickJS 在应用进程中运行，资源限制不等于操作系统级进程隔离。

本次不实现歌词/封面脚本 action、`local` 曲目的备用解析、完整 Node/浏览器环境、zlib、二进制/文件 multipart 上传或脚本自动更新。`updateAlert` 不自动打开链接、下载或执行代码。

## 验证

```sh
./gradlew :app:compileDebugKotlin
./gradlew :app:testDebugUnitTest --tests 'com.ljyh.mei.playback.source.lx.*'
./gradlew :UnblockNeteaseMusic:test
```

常规宿主测试使用项目自行编写的脚本和本机 HTTP 服务。外部样本仅在显式设置 `MEI_LX_SAMPLE_DIR` 并运行 `LxBlackBoxTest` 时由测试进程加载，默认跳过。测试覆盖 Promise、HTTP 回调/即时取消、加密向量、定时器、CPU/内存限制、试听边界、并发择优、失效 URL 单次探测和错误恢复。未做 APK 安装或视觉测试；用户样本的脱敏验证结果见 [2026-10-22 黑盒报告](lx-blackbox-2026-10-22.md)。
