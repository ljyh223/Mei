# 专辑详情年代样式实验

测试分支：`codex/album-era-styles`。实验仅替换专辑详情界面的封面展示，无额外设置开关。音乐库、歌手、发现页、搜索及其他列表中的专辑卡片沿用原实现。

## 年代与日期

| 发行年份 | 样式 |
| --- | --- |
| 1979 年及以前 | 黑胶封套与唱片 |
| 1980–1989 | 磁带收藏盒与可取出的磁带 |
| 1990 年起 | 可开合的 CD 盒 |
| 缺失、0 或超出有效年份范围 | 普通方形封面 |

`albumReleaseYear` 将接口的毫秒时间戳按 Asia/Shanghai 转为年份，不随用户设备时区改变年代。1970 年以前的负时间戳正常参与判断。既有模型用 0 表示缺失，详情接口同时接受未提供字段和显式 null。年代是这次 UI 实验的排他分界，不用于判断实际发行载体。

发行时间只消费专辑详情接口已有的 `publishTime`。不改动歌手、新碟、收藏专辑或搜索的数据模型，不额外请求专辑列表的年份。

## 展示与职责

- `ui/component/artwork/album/`：`AlbumMediaStyle.kt` 管理年份与格式；三个 `Album*Renderer`、`AlbumPackageRendering` 和 `CassettePackageMotion` 从 debug 迁移，共享实体造型、投影、开合、抽出和遮挡规则。
- `AlbumMediaArtwork`：应用级 Coil 加载器与约束尺寸解析；使用真实专辑封面、名称、艺人和年份，不引用 debug 演示素材或固定的演示专辑文字。舞台使用纯黑／纯白背景，图片失败有普通图标回退。模型加载期间显示骨架。
- `AdaptiveAlbumContent`：在同一业务入口下装配手机单栏、横屏和宽布局；专辑页背景使用纯黑或纯白，不再按封面取色染色。单栏列表顶部 contentPadding 保留状态栏和公共顶栏高度，玻璃渐隐与模型自带的上缘空白共用空间，头部只补不足的部分，避免双重留白；滚动视口保持全高，继续允许内容经过顶栏背后。播放、收藏、下载、搜索及歌曲菜单仍由原 `AlbumDetailScreen` 和 ViewModel 负责。
- 详情模型可横向拖动旋转，纵向仍交给页面滚动；点击切换开合／抽出。旋转和复位另有无障碍操作。状态按封面与格式区分，动画遵循系统动画时长设置，不持续自动播放。
- debug 的三套独立入口保留，面板复用迁移后的模型；本地演示图片仍留在 debug 资源中。

## 验证

运行 `:app:compileDebugKotlin` 与 `AlbumMediaStyleTest`，覆盖 1950／1969 的负时间戳、1979／1980 与 1989／1990 分界、设备时区变化、缺失／null／异常日期及详情元数据解析。`CassettePackageMotionTest` 检查机构端点与收回顺序。

按项目约定不主动安装 APK，不进行设备视觉验证；编译和单元测试不代表已确认实际模型比例、触摸手势和开盒画面效果。

## 模型打磨：纸卡、内页与倒影

- 三种模型共用中性材质：烟灰色壳体、浅色纸卡、深色正文和次要字色。封面保留原有颜色；文字的裁切宽度以材质的纹理逻辑宽度为准，不随反射 pass 的局部裁剪变化。磁带标签与黑胶中心标签分别限制文字范围，避免长标题压到 A／B 标记或越出标签。
- `AlbumDetailUiState.albumPackageTracks` 只读取详情原始 `songs` 的顺序、歌名和时长；不使用搜索后的 `displayedSongs`。磁带内页每页最多 8 首，CD 与黑胶每页最多 6 首并使用较大字号，显示原序号和已知时长，CD 内页、磁带纸卡及黑胶背封使用真实曲目，移除装饰性曲目线与演示条码。曲目缺失不编造，长专辑可在展开时切换内页，元数据缩短后自动夹紧当前页。
- `AlbumPresentation` 以同一条可逆的 0–1 进度协调机构和视角。CD 与磁带使用临界阻尼弹簧；黑胶使用 2.4 秒线性时间轴，经阶段缓动先抽出、稍停，再用约 1.6 秒翻背。拖动会停止自动展开，保留抓取时的姿态；磁带继续先开盒、再抬出和横移，黑胶先抽出后转向背封曲目，合上时按反序返回。无持续自动动画，遵循系统动画时长设置。
- `AlbumMirror` 替换原有地面椭圆阴影。镜像复用当前模型的原始几何和 Coil painter，在三维地面平面上反射顶点，再独立投影、判定可见面和深度排序。倒影与本体共用相机、缩放和视口，合成层只改变透明度，不再翻转或压缩屏幕画面，不创建 Bitmap 快照、不发起第二次图片请求，不改变舞台的外部尺寸。
- 专辑标题使用普通文字，移除文字倒影。普通信息保留弱化的年份与歌曲数量，移除重复的“专辑”标签；手机横屏沿用无额外标题的左栏。
- 本次仍只作用于专辑详情及其复用的 debug 模型，专辑卡片、发现页、搜索及音乐库不接入这些展示变化。

定向验证补充：展开／收纳顺序、黑胶先抽出再翻背、连续反向路径、长曲目分页与原序保留、未知时长、倒影在短窗口中的边界，以及内页翻页和元数据缩短的 Compose 语义／按钮交互。未进行截图、安装或设备视觉验收，实际材质与动效观感仍需设备确认。

## 录像反馈后的调整

- 倒影遮罩矩形关闭抗锯齿，离屏合成边界取整，透明渐隐先于裁切边界结束，并让遮罩覆盖边界之外，避免旋转时半像素边缘未被完整遮罩。该问题仍需设备确认深浅主题中的实际边缘表现。
- 分页控件按此次实验的明确要求使用 `MeiGlassSurface`，单独采样模型 Canvas，固定在舞台顶部右侧，不为了采样下移；这是本详情实验的局部使用，不扩大其他正文控件的玻璃范围。沿用全局玻璃开关、降低透明度和实色回退。
- CD 开角改为 135°，展开后减轻整体缩小，并让视角偏向曲目内页。黑胶增加更细密的沟槽、随角度移动的宽高光、纸张纤维和轻微封套磨损，素材仍由原有封面提供。
- 年份选择、歌曲数据与播放逻辑不变；卡片、搜索、发现、音乐库均保持原样。

## 旋转后的收纳与顶部留白

展开目标和实际动画进度由详情模型的局部状态分别持有：`detail` 只表达下一次操作的开合意图，`detailMotion` 绘制连续进度，`pausedDetail` 保存用户拖动时停下的姿态。拖动不再将中间进度写回操作目标，下一次点击可以从暂停处返回封套／包装。黑胶动画时长按剩余行程计算，保持原有慢速翻背节奏；重置会清除暂停姿态。

定向触摸测试先复现旧行为：取出后拖动会错误地把操作重新变成“抽出唱片”；修复后相同操作能收回。补充磁带开盒、取出、拖动、收纳和再次开盒，以及顶部分页位置检查。

单栏模型由两个渲染器共同使用 `AlbumModelCenterY` 和 `AlbumModelHalfHeight` 确定最小上缘空白。详情头部将这部分空间计入玻璃渐隐避让，只补余量并保留 1dp 保护。普通方形封面沿用完整避让；系统状态栏、顶栏按钮高度和其他页面均不调整。

## 三维平面反射

`AlbumProjection.kt` 提供三种模型共用的相机、透视投影、顶点反射与面朝向判定。先在开合后的模型坐标中确定地面高度 `groundY`，通过 `y' = 2 * groundY - y` 镜像顶点，再应用同一 yaw／pitch 视图和透视投影。镜面上的点保持不动，分处不同深度的接触边也能够衔接。

反射改变顶点绕序，所以倒影使用反向的正反面判断，保留原 UV 对应关系，并独立按镜像后的深度排序。不能复用本体已经剔除的面，否则镜面中应可见的底面会丢失。CD 先处理铰链姿态再反射；磁带和黑胶复用同一几何路径。视口只按本体确定一次，两遍共用同一个居中和像素缩放。

`AlbumMirror` 仅为已投影的反射面建立透明渐隐合成层。淡出从倒影实际投影范围开始，延伸到本体最近底边下方，避免以单一屏幕最低点裁掉远端接触边。倒影保持投影形状，区域之外自然渐隐；没有固定 36% 的纵向压缩或额外竖向位移。

定向数学测试覆盖接触点在不同深度与相机角度下重合、正面圆盘倒影半径保持、反射绕序、镜面可见底面、独立深度次序和淡出范围；交互测试继续回归开合、拖动收回及分页。不主动安装或进行设备视觉验收。

数学与绕序参考：[Khronos 平面反射说明](https://docs.vulkan.org/tutorial/latest/Building_a_Simple_Engine/Advanced_Topics/Planar_Reflections.html)。实现继续使用现有 Canvas 绘制，不引入新的 3D 引擎。
