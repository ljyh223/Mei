# 专辑详情封面展示与年代模型

年代模型已从 `codex/album-era-styles` 合入主线。展示仅作用于专辑详情，音乐库、歌手、发现页、搜索及其他列表中的专辑卡片沿用原实现。专辑详情与「外观 → 专辑封面展示」共用持久化的展示偏好，默认自动。

## 自动模式的年代与日期

| 发行年份 | 样式 |
| --- | --- |
| 1979 年及以前 | 黑胶封套与唱片 |
| 1980–1989 | 磁带收藏盒与可取出的磁带 |
| 1990–2009 | 可开合的 CD 盒 |
| 2010 年起 | 大幅静态封面 |
| 缺失、0 或超出有效年份范围 | 普通方形封面 |

`albumReleaseYear` 将接口的毫秒时间戳按 Asia/Shanghai 转为年份，不随用户设备时区改变年代。1970 年以前的负时间戳正常参与判断。既有模型用 0 表示缺失，详情接口同时接受未提供字段和显式 null。年代是这次 UI 实验的排他分界，不用于判断实际发行载体。

发行时间只消费专辑详情接口已有的 `publishTime`。不改动歌手、新碟、收藏专辑或搜索的数据模型，不额外请求专辑列表的年份。

## 展示与职责

- `ui/component/artwork/album/`：`AlbumMediaStyle.kt` 管理年份与格式；三个 `Album*Renderer`、`AlbumPackageRendering` 和 `CassettePackageMotion` 从 debug 迁移，共享实体造型、投影、开合、抽出和遮挡规则。
- `AlbumMediaArtwork`：应用级 Coil 加载器与约束尺寸解析；使用真实专辑封面、名称、艺人和年份，不引用 debug 演示素材或固定的演示专辑文字。舞台使用纯黑／纯白背景，图片失败有普通图标回退。只有专辑数据尚未就绪时显示舞台骨架；封面请求不会阻塞实体模型和交互，先绘制中性材质、纸卡及内页，图片成功后再贴到原模型上，失败使用图标回退。图片状态变化不重置旋转、开合或内页位置。
- `AdaptiveAlbumContent`：在同一业务入口下装配手机单栏、横屏和宽布局；专辑页背景使用纯黑或纯白，不再按封面取色染色。单栏列表顶部 contentPadding 保留状态栏和公共顶栏高度，玻璃渐隐与模型自带的上缘空白共用空间，头部只补不足的部分，避免双重留白；滚动视口保持全高，继续允许内容经过顶栏背后。播放、收藏、下载、搜索及歌曲菜单仍由原 `AlbumDetailScreen` 和 ViewModel 负责。
- 详情模型可横向拖动旋转，纵向仍交给页面滚动；点击切换开合／抽出。旋转和复位另有无障碍操作。状态按封面与格式区分，动画遵循系统动画时长设置，不持续自动播放。
- 原 debug 独立演示页、三个桌面入口及专用素材已移除；模型继续由专辑详情中的正式组件提供。

## 验证

运行 `:app:compileDebugKotlin` 与 `AlbumMediaStyleTest`，覆盖 1950／1969 的负时间戳、1979／1980 与 1989／1990 分界、设备时区变化、缺失／null／异常日期及详情元数据解析。`CassettePackageMotionTest` 检查机构端点与收回顺序。

按项目约定不主动安装 APK，不进行设备视觉验证；编译和单元测试不代表已确认实际模型比例、触摸手势和开盒画面效果。

## 模型打磨：纸卡、内页与倒影

- 三种模型共用中性材质：烟灰色壳体、浅色纸卡、深色正文和次要字色。封面保留原有颜色；文字的裁切宽度以材质的纹理逻辑宽度为准，不随反射 pass 的局部裁剪变化。磁带标签与黑胶中心标签分别限制文字范围，避免长标题压到 A／B 标记或越出标签。
- `AlbumDetailUiState.albumPackageTracks` 只读取详情原始 `songs` 的顺序、歌名和时长；不使用搜索后的 `displayedSongs`。磁带内页每页最多 8 首，CD 与黑胶每页最多 6 首并使用较大字号，显示原序号和已知时长，CD 内页、磁带纸卡及黑胶背封使用真实曲目，移除装饰性曲目线与演示条码。曲目缺失不编造，长专辑可在展开时切换内页，元数据缩短后自动夹紧当前页。
- `AlbumPresentation` 以同一条可逆的 0–1 进度协调机构和视角。CD 与磁带使用临界阻尼弹簧；黑胶使用 2.4 秒线性时间轴，经阶段缓动先抽出、稍停，再用约 1.6 秒翻背。拖动会停止自动展开，保留抓取时的姿态；磁带继续先开盒、再抬出和横移，黑胶先抽出后转向背封曲目，合上时按反序返回。无持续自动动画，遵循系统动画时长设置。
- `AlbumMirror` 替换原有地面椭圆阴影。镜像复用当前模型的原始几何和 Coil painter，在三维地面平面上反射顶点，再独立投影、判定可见面和深度排序。倒影与本体共用相机、缩放和视口，合成层只改变透明度，不再翻转或压缩屏幕画面，不创建 Bitmap 快照、不发起第二次图片请求，不改变舞台的外部尺寸。
- 专辑标题使用普通文字，移除文字倒影。普通信息保留弱化的年份与歌曲数量，移除重复的“专辑”标签；手机横屏沿用无额外标题的左栏。
- 这些模型展示变化只作用于专辑详情，专辑卡片、发现页、搜索及音乐库不接入。

定向验证补充：展开／收纳顺序、黑胶先抽出再翻背、连续反向路径、长曲目分页与原序保留、未知时长、倒影在短窗口中的边界，以及内页翻页和元数据缩短的 Compose 语义／按钮交互。未进行截图、安装或设备视觉验收，实际材质与动效观感仍需设备确认。

## 录像反馈后的调整

- 倒影遮罩矩形关闭抗锯齿，离屏合成边界取整，透明渐隐先于裁切边界结束，并让遮罩覆盖边界之外，避免旋转时半像素边缘未被完整遮罩。该问题仍需设备确认深浅主题中的实际边缘表现。
- 分页控件按此次实验的明确要求使用 `MeiGlassSurface`，单独采样模型 Canvas，固定在舞台顶部右侧，不为了采样下移；这是本详情实验的局部使用，不扩大其他正文控件的玻璃范围。沿用全局玻璃开关、降低透明度和实色回退。
- CD 开角改为 135°，展开后减轻整体缩小，并让视角偏向曲目内页。黑胶增加更细密的沟槽、随角度移动的宽高光、纸张纤维和轻微封套磨损，素材仍由原有封面提供。
- 年份选择、歌曲数据与播放逻辑不变；卡片、搜索、发现、音乐库均保持原样。

## 旋转后的收纳与顶部留白

展开目标和实际动画进度由详情模型的局部状态分别持有：`detail` 只表达下一次操作的开合意图，`detailMotion` 绘制连续进度，`pausedDetail` 保存用户拖动时停下的姿态。拖动不再将中间进度写回操作目标，下一次点击可以从暂停处返回封套／包装。黑胶动画时长按剩余行程计算，保持原有慢速翻背节奏；重置会清除暂停姿态。

定向触摸测试先复现旧行为：取出后拖动会错误地把操作重新变成“抽出唱片”；修复后相同操作能收回。补充磁带开盒、取出、拖动、收纳和再次开盒，以及顶部分页位置检查。

单栏模型由两个渲染器共同使用 `AlbumModelCenterY` 和 `AlbumModelHalfHeight` 确定最小上缘空白。详情头部将这部分空间计入玻璃渐隐避让，只补余量并保留 1dp 保护。普通方形封面沿用完整避让；系统状态栏、顶栏按钮高度和其他页面均不调整。

## 三维平面反射

`AlbumProjection.kt` 提供三种模型共用的相机、透视投影、顶点反射与面朝向判定。先在开合后的模型坐标中确定地面高度 `groundY`，通过 `y' = 2 * groundY - y` 镜像顶点，再应用同一 yaw／pitch 视图和透视投影。镜面上的点保持不动，分处不同深度的接触边也能够衔接。

反射改变顶点绕序，所以倒影使用反向的正反面判断，保留原 UV 对应关系，并独立按镜像后的深度排序。不能复用本体已经剔除的面，否则镜面中应可见的底面会丢失。CD 先处理铰链姿态再反射；磁带和黑胶复用同一几何路径。视口只按本体确定一次，两遍共用同一个居中和像素缩放。

`AlbumMirror` 仅为已投影的反射面建立透明渐隐合成层。淡出从倒影实际投影范围开始，延伸到本体最近底边下方，避免以单一屏幕最低点裁掉远端接触边。倒影保持投影形状，区域之外自然渐隐；没有固定 36% 的纵向压缩或额外竖向位移。

定向数学测试覆盖接触点在不同深度与相机角度下重合、正面圆盘倒影半径保持、反射绕序、镜面可见底面、独立深度次序和淡出范围；交互测试继续回归开合、拖动收回及分页。不主动安装或进行设备视觉验收。

数学与绕序参考：[Khronos 平面反射说明](https://docs.vulkan.org/tutorial/latest/Building_a_Simple_Engine/Advanced_Topics/Planar_Reflections.html)。实现继续使用现有 Canvas 绘制，不引入新的 3D 引擎。


## 详情重设计与固定展示模式

- `AlbumArtworkModeKey` 独立保存「自动／动态封面／年代模型／静态封面」，由专辑更多菜单和外观设置共同编辑，作用于所有专辑详情，不影响全屏播放器或列表卡片。
- `AlbumArtworkPolicy` 是唯一的展示选择入口。自动优先使用可用动态封面；没有动态时按上表选择模型或静态。固定静态与模型时不请求视频；年代模型另有「自动判断／黑胶唱片／盒式磁带／CD／DVD 光盘」子选项。自动判断沿用原 `albumMediaStyle`，所以 2010 年起仍显示 CD，缺失年份回退静态；固定某个模型时所有专辑详情均使用该模型，包含缺失年份的专辑，标签继续显示真实发行年份，不伪造日期。固定动态没有可用视频或播放失败时回退静态，自动模式失败则回退年代规则。
- 专辑动态素材由 `AlbumDetailViewModel` 复用 `DynamicCoverRepository.resolve` 和已有 Apple Music 专辑匹配、视频缓存。只使用 Apple 专辑动态资源，不将首曲的网易云歌曲动态素材当作整张专辑封面。请求使用专辑标题、专辑艺人和封面参与匹配，现有动态总开关、Apple 来源选择和英语标题限制继续生效。模式或请求变化时取消旧任务并清空旧结果，界面同时校验结果对应的代表歌曲，避免跨专辑残留。失败不影响详情数据、曲目和播放。
- `AlbumArtworkHeader` 在静态／动态分支将大图铺满头部并向纯色背景渐隐，身份信息居中；普通页面图片直接使用共享 Coil。视频复用静音循环的 `DynamicCoverView`，跟随页面 Resume 暂停／恢复，组合退出释放播放器。模型分支保留三维舞台、旋转、开合与倒影。
- 共享 `AlbumActions` 固定为「随机播放—播放—下载」，主按钮宽度最多 144dp、不填满剩余空间，随机图标复用 `ic_player_shuffle`；主播放使用当前页面对应的高对比实色，两个次级操作为普通实色圆形按钮，不增加玻璃范围。随机播放从完整专辑随机选第一首，并开启播放服务的随机模式；主播放从第一首开始并显式关闭随机模式。两者均不使用页内搜索过滤后的列表。
- 收藏统一进入 `AlbumDetailMoreButton`，保留收藏／取消收藏、状态加载、失败重试以及禁止重复操作的条件。手机横屏将更多移到右栏歌曲标题旁，左侧保留展示与三项播放／下载操作；平板和手机单栏共用身份信息及按钮组件。简介只预览一行，溢出时在同行显示“展开”，全文仍使用原弹层。

验证：封面年代与优先级、固定模式回退、收藏状态菜单、展示选择、三个播放／下载操作的顺序与可用状态，以及手机横屏的操作位置；继续回归原模型开合、倒影数学和队列选择测试。未安装 APK，未进行设备视觉验收。


## 动态封面色板

`AlbumArtworkTheme` 按当前视频变体选择 AM 的 `CoverPalette`。竖屏优先竖版资源的色板，缺失字段回退方形资源；横屏使用方形资源。`bgColor` 同时用于页面背景与视频下缘渐隐，`textColor1–4` 分别参与主文字、次文字、元信息与强调操作的配色。只有字段缺失、无效或对比度不足时才回退，文字与背景至少保持 4.5:1；模型分支与平板、手机横屏的静态分支继续使用原主题的黑白舞台；手机竖屏静态分支在封面解码后使用下述图片配色。

顶栏和更多按钮在本页面作用域内通过 `LocalMeiChromeContentColor` 消费校验后的 AM 主文字色，玻璃开启、关闭与降低透明度的底座规则不变。系统状态栏通过 `LocalPageLightStatusBar` 跟随页面背景选择黑／白图标，页面暂停、退出或回退为普通封面时释放请求；播放器有更高优先级，迟到的旧页面释放操作不能清除新页面的请求。

定向测试覆盖深浅色板、四级文字、竖版字段回退、非法颜色、低对比度保护、顶栏前景色、短播放按钮，以及页面／播放器状态栏优先级和恢复。未进行设备视觉验收。


### 大封面与正文的衔接

静态／动态大封面由 `AlbumCoverHero` 先测量标题、歌手及元信息，再决定正文起点。视频与静态占位共用一次渐隐：过渡带从标题起点上方 24dp 延伸到其下方 72dp，在标题下缘平滑混入页面精确背景色，不再在标题之前铺一整段大面积遮罩；身份信息不再另叠接近不透明的矩形底色。长标题和字体缩放会扩展头部并保留可见图像空间，不使用固定百分比猜测文字位置。

大封面仍位于顶栏下方时，专辑页显式请求透明顶栏背景；只有独立图标按钮保留公共材质。封面／文字边界越过顶栏后，或打开页内搜索时，恢复公共自动背景；开启降低透明度时继续服从公共实色规则。年代模型沿用原顶栏策略。


### 年代模型的固定造型与即时设置

`AlbumModelModeKey` 保存模型子选项。`rememberAlbumArtworkPreferences` 同时观察外层模式与模型偏好，专辑更多菜单和外观设置共享该入口；选择后当前页即更新，无需重新进入，后续所有专辑详情共用该值。两项偏好在同一次 DataStore 编辑中提交，避免短暂显示旧模型。重新从其他模式切入年代模型时重置为自动判断；在年代模型内选择固定造型会持久保存。外层自动模式完全忽略固定造型，保留动态优先及 2010 年分界规则。

`AlbumArtworkPolicy` 解析最终造型，详情舞台通过 `AlbumMediaArtwork.style` 传入；安全留白也按实际造型计算。切换造型时重置该模型的旋转、开合及分页，保留真实专辑资料与歌曲列表。卡片及播放器不消费此设置。


### 手机横屏

手机横屏在专辑详情中禁用动态封面：页面请求会取消并清空已有动态素材，展示策略也独立禁止视频与 AM 视频色板，避免旋转后的旧结果闪回。此限制不修改用户保存的封面偏好；回到竖屏恢复原选择。自动与固定动态模式在横屏按发行年代回退模型或静态封面；固定模型与固定静态仍按用户选择。平板及全屏播放器不受此页面限制影响。

左栏提高宽度上限，并使用完整可用高度绘制模型，不强制套用竖屏舞台比例；静态封面在可用区域内保持正方形。播放与更多通过 `MeiArtworkGlassActions` 浮在左侧封面上，单独采样封面，沿用公共玻璃及关闭玻璃的实色回退。随机播放、下载和收藏移入更多菜单。窄横屏回退单栏时也只在封面中保留这两个操作。

专辑导航启用横向全宽背景，背景绘制到摄像头／刘海安全区；正文、舞台和控件仍由公共边距叠加系统安全区与常驻侧栏，避免开孔处露出不同的外层主题底色。


## 手机竖屏静态封面背景

手机竖屏且最终展示为静态封面时，`AlbumStaticArtwork` 使用同一份 Coil painter 绘制清晰方形封面及向下拉伸三倍的倒影，再由共享 `ui/component/artwork/backdrop/` 施加可变模糊与独立渐隐。模糊清晰区向下扩展 0.6 倍图片宽度，以保留完整封面；透明度从 0.9 倍宽度过渡到 1.4 倍宽度。原先按真实标题位置测量的渐隐继续保证长标题下的过渡，文字与按钮不参与图片模糊。Android 13+ 使用共享 AGSL，旧版本保留清晰图、图片配色和原有渐隐，不显示未经模糊的倒影。

页面配色由实际解码后的图片提供：`AdaptiveAlbumContent` 持有当前专辑和资源对应的局部颜色状态，`AlbumDetailActions.onStaticArtworkChanged` 经 Screen／ViewModel 调用共享颜色仓库。图片、倒影和取色不额外发起图片请求；取消、资源变化或加载失败撤销当前配色，取色失败保留中性回退。背景采用与艺人页一致的亮度调整，正文、元信息和顶栏前景校验至少 4.5:1 对比度，状态栏跟随该页面所有者。模型、动态封面、平板和手机横屏保留各自原有选择和展示规则。

定向测试覆盖单次解码／取色与无关状态变化时的复用、静态配色对比度、仅在手机竖屏静态分支启用，以及共享 shader 的清晰区参数。艺人默认参数、视频合成与已有专辑控制继续回归。未安装 APK、未启动模拟器、未进行设备视觉验证。
