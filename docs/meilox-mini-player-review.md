# MeiloX mini player 分支检查

检查分支：`test/meilox-mini-player`，起点 `d4bd8b1`。保留现有四标签、独立搜索及滚动收缩联动。本轮只修正阅读性、开放材质参数和直接相关的交互问题。

## 已落实

- 玻璃底座与前景内容分层绘制。Haze 的 Sources 路径原本就不会直接模糊子文字；本轮额外把光学前景与高光放到独立底层，再绘制中性遮蔽和文字图标，避免把对比不足误诊为字体被模糊。
- 默认底色浓度 60%、模糊 20、折射 25%、高光 20%、背景色彩 65%，默认开启增强清晰度。增强模式进一步提高底色遮蔽，未选中标签与歌手使用完整前景色；仍可自由调整。
- 外观 → 玻璃材质调节：本地实时预览，通透/均衡/清晰预设，五项参数、增强清晰度、恢复默认。拖动时预览，松手时保存；预设一次性保存全部参数。配置读取处理缺失、越界和非有限值。
- 导航图标 24dp、标签 13sp；保留选中背景和语义。选中图标在收缩过程中保持显示并连续移动，不再先淡到透明、再替换成另一枚图标。
- mini player 播放与下一首触控区由 40dp 提高到 48dp；下一首逐渐消失时停用点击。
- 搜索和关闭按钮遵守底栏 interactive 状态，隐藏期间不再保留可触发的按钮。
- 底栏高度按系统字体放大；紧凑播放器的垂直位移根据相同几何计算，移除固定 66dp 对大字体的假设。默认字体保持原先 64dp / 66dp 几何。
- 保留 SDK、低内存和省电降级。设置页会说明当前处于静态样式，避免滑块调整后用户误以为未生效。
- 设置等页面统一使用固定顶栏与滚动大标题；歌单列表内容可滚过顶栏下方，标题与背景分别渐入。
- 顶栏使用真实渐进模糊：上部最大半径 10dp，从高度的 42% 起递减至零；底色遮蔽同步递减，背景额外向下延伸 34dp，不增加布局高度。移除去色、光照与边缘阴影，文字和按钮保持独立。
- 搜索由外层统一处理和消费输入法 inset，底部搜索栏与提示层不再各自叠加键盘高度；提示层按实测底栏高度避让。
- 手机首页正常内容按状态栏留白，取消原先额外的 64dp 顶部空白；发现页、搜索结果和音乐库也同步整理各自的顶部位置。
