# 外观设置

外观首页只保留常用主题与材质，以及三个设置入口。各页继续直接观察已有 DataStore 偏好，不复制设置状态、不迁移或更改已存储的键与默认值；进入页面不写入偏好。

| 页面 | 内容 | 路由 |
| --- | --- | --- |
| 外观 | 主题模式、动态主题、主题色、液态玻璃与材质入口 | `setting/appearance` |
| 内容展示 | 歌单封面与表头、专辑封面展示与模型、AM 歌手人像、动态封面来源、播放器原图 | `setting/appearance/artwork` |
| 播放界面 | 播放条、歌名显示、进度条、背景速度与启停 | `setting/appearance/player` |
| 动画与动效 | 页面切换样式、速度、播放器面板切换 | `setting/appearance/animation` |
| 背景高级设置 | 渲染精度、网格细分，从播放界面进入 | `setting/appearance/player/background` |

`AppearanceSettingsPage` 复用公共顶栏、滚动容器与内容边距，各子页只装配本页偏好。原图开关继续只控制播放器高清请求；AM 歌手人像仍默认关闭，与动态封面来源独立。专辑封面和模型通过已有 `rememberAlbumArtworkPreferences` 读取同一份快照并原子更新相关键；选择模型类别仍按原规则从年代自动选择开始。

歌词继续使用设置首页的独立入口，外观不再重复链接。Debug 开关移到「关于 → 开发者设置」，保留原键和默认值，用于调试复制操作与艺人图片来源。开发者设置继续保留动态封面诊断，入口沿用关于页现有开发者模式规则。

手机竖屏通过主导航逐级进入与返回。平板及满足宽度的手机横屏保留 `SplitSettingsHost`：所有新路由都归属外观分类，左侧分类栏保持在 NavHost 外，右侧无页面切换动画；更换分类时仍清理旧详情栈。背景高级设置返回播放界面，播放界面再返回外观；跨 Tab 保存和恢复沿用主导航，设置值由 DataStore 持有。

导航测试覆盖子页分类、右栏即时切换、逐级返回、跨 Tab 恢复和更换分类时保留设置根。按协作约定只运行编译与定向状态／导航测试，不安装 APK 或做设备视觉验证。
