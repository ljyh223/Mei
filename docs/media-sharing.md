# 链接分享

歌曲菜单提供“分享链接”和“复制链接”；播放器更多操作中的“分享”打开系统分享面板。歌单与专辑详情顶栏共用一个玻璃“更多”按钮，菜单提供页内搜索、分享链接、复制链接。进入页内搜索后，该位置显示关闭按钮，关闭时清空查询并恢复“更多”。菜单复用歌曲菜单的紧凑条目组件。

公共链接由 `MediaShareLink` 统一生成，使用网易云歌曲／歌单／专辑网页地址。系统面板接收 `text/plain`，内容为标题、歌手或创建者与公开网页链接，不携带播放地址、文件路径、Cookie 或用户标识，不指定接收应用，也不自动发送。

本地扫描歌曲的内部数字 ID 不能作为网易云 ID。`MediaMetadata.neteaseId` 对在线歌曲默认为原歌曲 ID；下载歌曲沿用目录 ID；本地歌曲仅使用有效的 `matchedNeteaseId`，未匹配时隐藏链接入口。每日推荐等负数临时歌单不显示分享按钮。不可用的公开 ID 记为 0，避免播放队列省略 null 字段后恢复成内部 ID。旧本地队列没有明确保存公开 ID 时也暂不提供链接。该字段有默认值，兼容既有序列化元数据，不涉及 Room 表结构变化。

验证覆盖链接类型、长整数 ID、无效 ID、名称缺失／换行、本地匹配与未匹配歌曲、下载歌曲、旧序列化数据，以及系统 chooser 的 MIME、文本、任务栈和失败回退。按照项目约定不安装 APK 或进行设备视觉检查；真实接收应用的展示与网页访问仍待设备验证。
