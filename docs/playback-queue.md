# 播放队列

## 状态归属

Media3 的播放列表与原生 shuffle order 是唯一的活动队列。`Queue` / `ListQueue` / `EmptyQueue` 仅描述一次替换队列的输入，不再提供未接入的分页、加载状态或监听接口。

- `playback/queue/PlaybackQueueManager.kt`：统一替换、插队、追加、按项播放、移除、移动、播放模式和 FM 会话；命令在播放器主线程执行。
- `PlaybackQueueState.kt`：从 Media3 投影只读展示项，适配原生随机顺序与双播放器；不保存另一套可独立修改的列表。
- `QueueEntry.kt`：每次入队分配独立 `entryId`，来源描述和媒体资料所属目录分别保存；同一首歌多次入队也能分别定位。
- `QueueMetadataResolver.kt`：按媒体目录批量获取资料。网易云走歌曲接口，本地走已有 SongRepository，MusicFree 走已有插件记录。某一目录失败不影响其他目录，不将本地缺失项回退到网易云同号歌曲。
- `PlaybackQueueSnapshot.kt`：快照编解码及旧格式兼容。
- `MusicService`：装配资料获取回调，负责 DataStore 读写、500ms 合并保存及周期性进度保存。
- `PlayerConnection`：转发状态和命令；手机、横屏、平板都使用 `PlaylistContent`，界面不再自行监听 timeline 或维护可变队列。

队列面板通过 `queueState` 订阅后，管理层才构建完整的展示列表；面板关闭时不再响应每次 timeline 变化生成 UI 列表。服务的快照保存独立于界面订阅。FM 模式为单独的小型 StateFlow，播放控件持续观察它即可。

## 播放顺序与编辑

顺序模式显示 Media3 原始列表；随机模式显示原生 shuffle order，首次打开定位当前项。列表包含一轮播放的所有项，当前项后方就是接下来的播放顺序，到末尾是否回绕仍由循环设置决定。

所有交互传递 `entryId`，在执行时查找实际位置。补资料、重复歌曲、拖动或 FM 清理历史都不会让点击落到过期索引。

- 顺序拖动调用 Media3 move；随机拖动只修改原生 shuffle order，不重排原始列表。关闭随机后仍回到原始列表。
- “下一首播放”将新增项放到当前项后方，并在随机模式下同步调整遍历顺序，保持其余项目的相对顺序。
- 随机顺序编辑通过双播放器适配入口触发原有过渡取消回调，避免备用播放器继续按旧顺序接管。
- 最后一首歌曲仍不能从普通队列面板移除。过期项的点击、移动、删除会安全忽略。
- 模式切换读取播放器当前状态，循环设置通过已有 `PlaybackRepeatMode.kt` 应用。FM 保持自身模式，不能切换随机。

## 请求生命周期

替换队列、启动 FM 和恢复快照会建立新的队列会话。旧会话的子任务取消；FM、输入列表和元数据在请求返回后还会校验会话版本，防止不响应取消的调用回写到新队列。释放管理器同样使旧版本失效。

FM 有种子和无种子入口均替换旧列表、关闭随机、开启循环。有种子时立即放入歌曲或占位项，资料异步补全，不等待接口后再决定启动哪个队列。补歌按会话去重请求，并过滤当前列表内重复的歌曲。FM 从一个地方补歌，服务不再重复监听并发起补歌。

元数据以“媒体目录 + 歌曲 ID”去重，不把本地负数 ID 当作 MusicFree。返回结果只替换当前会话中同目录同 ID 的占位项，保留原 `entryId`、来源和目录类型；失败项在再次打开或滚动到可见范围后可重试。可见范围加载传递具体项标识，随机、拖动与移除后不会请求错误位置。

## 保存与恢复

快照保存原始列表、每次入队的标识／来源／媒体目录、当前项索引、进度、当前歌曲资料、FM 模式、随机开关、循环模式，以及用 `entryId` 表示的完整随机遍历顺序。只保存当前歌曲的完整资料；其他歌曲仍按目录从原有数据源补齐，不把整批歌曲或临时播放 URL 写进快照。

恢复时先放入原始列表及当前位置，恢复随机遍历顺序，再应用当前设置下的循环规则和随机开关。恢复保持暂停。即便当前关闭随机，也保存潜在的随机顺序，之后开启时继续使用。普通队列、无种子 FM 或仍在等待输入的用户操作均优先于启动快照。

旧快照无随机顺序时沿用 Media3 生成的顺序，无媒体目录时从来源及 ID 推断。新快照中的模式优先于旧的独立偏好键；循环开关仍以当前设置为准。损坏的可选随机顺序被忽略，不丢弃有效歌单；重复项标识或非法基础字段拒绝恢复。

## 验证边界

定向 JVM／Robolectric 测试使用内存数据源，不请求真实音频或接口，覆盖 FM 迟到响应、会话切换、随机列表拖动、重复歌曲身份、插队和重启顺序、本地与 MusicFree 负数 ID 隔离、缺失资料重试、界面按需订阅、启动恢复优先级及旧快照兼容。原有循环边界、媒体键与过渡算法测试继续执行。

编译及测试不等于设备验收；真实拖动手感、音频解码、网络失败表现和智能过渡的听感仍需设备验证。
