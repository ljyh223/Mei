# 图片加载约定

普通 Compose 页面直接将原始 URL 交给现有 Coil `AsyncImage`。不要在页面拼接 CDN 参数，也不要用自定义缓存键隐藏图片尺寸。

应用级 `ArtworkRequestInterceptor` 在 Coil 缓存查找之前读取组件解析后的像素尺寸（包含屏幕密度），取已知长边并向上归档：192、512、1024px。无法取得尺寸时使用 512px；超过最大档也不会自动请求原图。网易云 URL 统一使用 `imageView`、`thumbnail`、WebP 和质量 80，替换重复的旧尺寸参数，保留其他参数及动态图片。`ImageUrls.kt` 是尺寸和 URL 规则的唯一入口。

手机与平板全屏播放器统一使用 `rememberPlayerArtworkRequest(url, originalCover)`：原图开关关闭时固定请求 1600px，开启时请求原图，显式绕过普通组件自动分档。请求同时固定解码尺寸：普通高清为 1600px，原图为 `Size.ORIGINAL`，不由 mini bar 或展开动画中的组件尺寸决定。1600px 是播放器专用规格，不加入普通组件的自动档位。全屏图片预览使用 `rememberOriginalArtworkRequest(url)`，同样显式按原图尺寸解码，避免只取得原图 URL 却仍解码成缩略图。这些高清请求优先使用已有内存缓存，其次只从磁盘缓存查找缩略图，再加载目标高清图；不会为了占位额外下载小图，高清图失败时保留占位图。小图只用于占位，最终结果仍由 Coil 按高清请求的尺寸校验缓存并加载。没有占位缓存时沿用组件的空状态。保存图片使用 `ImageRequest.Builder.originalArtwork(url)` 显式绕过缩略规则。

取色、背景采样、通知栏及预加载没有组件尺寸，应在 `ImageRequest.size` 指定处理尺寸，网络图片同样自动归档。下一首图片由播放服务触发 192px 小图预加载；队列、切歌、随机或循环模式变化时重新选择实际下一首，目标改变时取消旧请求。页面消费同一应用级 ImageLoader 的缓存。当前歌曲的高清请求由播放器组件发起，收起状态下的尺寸不降低其解码规格，展开无需重新请求；下一首不额外预下载高清图或原图。

本地路径、content URI 和非网易云域名保持原样，不套用网易云参数；其他 CDN 的服务端缩略需要单独适配。这里只统一网络请求规格，不改变组件在界面上的 dp 大小。

包含 `|`（含 `%7C` 编码）的 NOS 处理链或 `watermark` 操作时保留整个 URL，不替换其中的 `type`、`thumbnail` 等参数，也不额外追加缩图。此类参数按操作阶段解释，水印的 `type=1` 不是图片编码格式；原图开关也不移除 API 提供的水印处理链。这类资源沿用接口提供的尺寸，不保证符合普通分档或播放器 1600px。

首页推荐卡片的底色优先复用实际显示完成的位图，在后台取色，不另行下载小图。硬件位图只对临时软件副本取色，不能回收 Coil 的原图；动画等非位图图片沿用已有颜色或中性回退，不从后台并发绘制同一动画对象。缓存和请求顺序见 [首页加载](home-feed.md)。

## Apple Music 艺人图片模板

艺人页直接向 Coil 传入 Apple 返回的 `mzstatic.com` 图片模板。`ArtworkRequestInterceptor` 在解析组件实际像素尺寸后，由 `ImageUrls.kt` 统一替换 `{w}`／`{h}`，复用 192、512、1024px 档位；Logo 在公共入口选择 PNG 以保留透明背景。已经解析为具体尺寸的 Apple URL、其他 CDN、本地资源不进入这套模板解析。普通艺人图片与 Logo 各自加载，不等待整批资源。页面无资源或主图失败时回退原布局，状态与匹配见 [艺人详情](artist-detail.md)。
