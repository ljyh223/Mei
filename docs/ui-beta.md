# Mei UI beta

新版 UI 已整合到原项目目录的 `bate` 分支，以 main 的 `338a63f` 为基础，包含已提交的序列化迁移、歌词悬浮窗、播放器动画及 USB 播放更新。切换到 `bate` 即可编译测试，无需单独加载工作区。不安装或发布 APK。

## 设计规则

- 使用接近中性的明暗背景；动态封面取色保留在主题强调色、选中状态和播放器中。
- 统一字体大小、字重、行高、卡片与控件圆角。分类颜色独立于当前播放歌曲，图标保持同一套 Rounded 风格。
- 首页优先显示推荐封面，并保留空内容和请求失败的重试入口；每日推荐、听歌识曲、本地音乐不再作为首页快捷入口。
- 底部导航、mini player 和搜索使用同一套 Haze 玻璃。玻璃只采样内容层，页面层不包含采样它的导航、搜索和播放浮层。
- 全屏播放器只有标题栏的 like / more 保留玻璃，并采样播放器自己的背景源；上一首、播放、下一首和底部工具栏使用普通图标，不采样浏览页面。
- 保留导航的测量高度和播放器锚点；迷你播放器与底部导航使用同一 20dp 侧边留白，封面起点同步调整。
- 外观设置提供“流体玻璃”开关。低内存、现有低电量/省电策略会停用实时材质，保留布局与操作。
- 导航与按钮保留文本或可访问名称、选中和禁用语义；主要触控区域至少 48dp。新排版使用系统字体以保留中文与字体缩放支持。
- 主题在根节点提供 `onBackground` 作为默认内容色，避免没有显式颜色的文字在深色模式下回退成黑色；推荐卡标题固定单行。

## 参考与边界

MeiloX 用于理解完整材质和交互的一致性，NeriPlayer Clean 用于理解中性表面、分类色彩和内容层次。这里独立实现组件，没有复制两个参考项目的源码。流体玻璃统一使用 Haze 2.0.1（`haze` + `haze-glass`），不再使用 Backdrop；图片继续使用 Coil。

## 验证

按项目约定进行 Kotlin 编译、配色对比度及现有导航/播放器定向单元测试。不安装或更新 APK，不运行设备视觉测试。编译和单元测试不能证明设备上的玻璃表现、帧率、大字体或横竖屏布局已经通过视觉验证。

## 第二轮页面统一

- 音乐库：移除未实现的云盘占位入口，最近播放、本地音乐与下载改用统一彩色图标；收敛头像标题、分类标签和收藏行。未登录时也保留本地入口；同步失败提供重试与本地音乐入口。
- 发现：手机固定双列网格，平板保持自适应；分类按钮使用共享选中语义与 48dp 最小高度。加载时显示网格骨架；空分类和失败均提供恢复操作。
- 专辑：详情页沿用 main 分支的沉浸式封面 hero 与渐变操作区，不再套用歌单的共享标题布局。
- 歌单：封面、标题、创建者和统计信息居中；操作行居中，收藏和下载只显示图标并使用页面内中性圆钮，播放全部保留文字并居中。封面仍可预览。
- 歌曲列表：分页失败的重试按钮接入 Paging retry；首屏加载失败、加载中和空歌曲列表有明确状态。排序时的 headerOffset 和歌曲索引逻辑保留。
- 所有变化已整合到 `bate` 分支，继续保留不安装 APK、不进行设备视觉测试的约定。

## Haze 与 Neri mini player 试验

- 玻璃底座从 Backdrop 迁到 Haze：`NavHost` 作为页面 source，底部导航、mini player 和搜索采样页面；播放器背景作为独立 source，仅服务 like / more。
- 实时玻璃仍受“流体玻璃”开关、低内存和省电策略控制，默认在 SDK 33+ 启用；更低版本保留静态表面。
- mini player 先按 NeriPlayer Clean 的信息结构实现：64dp 高、40dp 封面、标题/歌手两行、播放和下一首两个纯图标按钮，外形使用与底部导航一致的胶囊。
- 该试验在 `test/neri-mini-player` 分支进行，待设备视觉确认后再决定是否合并回 `bate`。
