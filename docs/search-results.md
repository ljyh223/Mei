# 搜索结果

## 页面与交互

- 普通搜索和历史记录默认进入「综合」；歌曲、歌手、专辑建议项保留明确的分类意图。
- 手机 `PhoneApp` 与平板 `TabletApp` 的底栏搜索共用 `MeiAppState.submitSearch`，统一记录历史、编码路由关键词与提交搜索；结果页保留同一导航 entry 下的业务状态，不恢复已删除的旧搜索覆盖层。
- 结果页共用固定的返回按钮、实色搜索框、分类栏及输入行为；手机和平板分别注入内容展示，应用外层不叠加第二个顶栏搜索框。搜索框获得焦点后显示既有建议与历史，返回操作撤销未提交编辑。
- 综合页依次展示最佳匹配（至多 2 项）、单曲（5 首）、歌单（3 个）、专辑（横向预览）、其他歌手与推荐歌曲。空分区隐藏；最佳匹配中的歌手、专辑、歌单在后续预览去重，完整分类不去重移除它们。
- 「查看全部」切换相应分类。分类独立缓存结果和滚动位置，详情返回保留当前位置。歌曲、推荐歌曲分别创建播放队列，不混入其他分区。
- 首次加载提示延迟 250ms 出现，快速返回直接显示结果，不延迟结果本身。综合页在内容区靠上居中显示小转圈和「正在搜索…」，不预设返回分区；分类页使用对应骨架：单曲复用歌曲行，歌手为圆头像行，专辑／歌单复用实际封面行的尺寸与文字布局。切回缓存结果不重复显示加载提示，分页继续保留已有内容并在底部转圈。
- 首次失败可重试，续页失败保留已有条目并在底部重试。空分类提供「查看综合结果」。
- 图片直接使用应用级 Coil 组件，沿用自动尺寸分档与缓存，逐张显示。边距遵循 `meiPageGutter()`，底部预留播放器安全区。

## 平板展示

- 搜索目的地由 `MeiPageContent.Search` 装配，`TabletPageContent` 注入 `TabletSearchResultScreen`；手机沿用共享单列。共用原搜索路由、导航 entry 的 ViewModel、缓存、播放与菜单操作，不另建搜索数据源。
- 平板内容居中且最大 1280dp，搜索输入框最大 640dp。布局按内容的实际宽度、公共 gutter 和字体比例计算；28dp gutter、普通字体时，综合双栏从 896dp 起启用。主栏保留至少 480dp 正文空间，副栏至少 280dp，栏间距 24dp；字体增大提高门槛。只有两边都有内容时才分栏。
- 综合主栏显示最佳匹配、单曲和推荐歌曲；副栏显示专辑横向预览、歌单与其他歌手。只有一个纵向滚动容器，预览有条数上限，空分区不占位。较窄窗口按主结果、集合、推荐的顺序单列显示。
- 单曲分类在宽度足够时复用现有平板歌曲行，展示序号、歌曲、专辑、时长与更多操作，并提供对应表头；较窄窗口或大字体回退紧凑歌曲行。歌手使用圆头像网格，专辑和歌单使用封面网格。网格列数按字体与宽度计算，使用资源 ID 为键，不按固定设备类型决定。
- 初次分类加载仍延迟 250ms，使用 `SkeletonShimmerHost`。歌曲骨架和表头按同一列布局显示；圆头像、封面、标题及副标题均复用实际网格单元的尺寸，骨架列数与结果一致，不下载占位图且不能点击。综合初次加载维持小转圈，不编造未知分区；分页保留已有结果，仅在底部显示加载或重试。
- 每个关键词与分类继续使用原来的可保存状态作用域，平板网格保留返回后的滚动位置；同一网格调整列数时复用同一个滚动状态。手机／平板展示切换共用业务缓存，但不承诺不同展示的像素滚动偏移完全一致。

## 请求与解析

- 综合搜索使用 `interface3.music.163.com/xeapi/search/complex/page/v3`，通过现有 `XeApiClient` 发送表单。关键词在 `keyword` 字段，`extInfo` 为 JSON 字符串；XEAPI 容器统一添加一次 `e_r=true`。搜索使用 `page_search_all` 上下文和运行时获取的 V2 反作弊 token。
- 请求仅包含所需业务参数，不复制抓包中的 Cookie、令牌、设备标识、广告设备信息或实验分组。
- 分类搜索保留 `/api/search/get/` 及 `s/type/limit/offset` 参数；综合结构与分类结构由 `SearchResponseParser` 分别映射，不按路径前缀互换加密协议。
- 综合解析支持最佳匹配、歌曲、歌手、专辑、歌单和推荐歌曲，忽略尚未实现的资源及未知区块；不执行服务端提供的应用跳转地址。
- 分类偏移量按原始返回条目计算，显示列表按资源 ID 去重。优先使用结构化 `hasMore/more` 或总数判断续页；总数缺失时按页大小判断，空页、偏移不前进或整页重复时停止。
- 综合样本只有首页 cursor，因此当前综合页不猜测续页协议；完整结果通过分类页查看。`more.text` 内的数字不作为结构化总数。
- 搜索词变化时取消旧请求并递增请求代次；旧响应不得覆盖新词的可见结果或分类缓存。切换分类时允许已有请求完成并缓存。

## 验证边界

定向测试覆盖请求封装、混合区块解析、空值和业务错误、分页偏移、去重、请求竞态与失败重试。编译与单元测试不代表真实账号下接口或设备视觉效果已验证；不主动安装 APK 或执行视觉测试。
