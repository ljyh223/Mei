# 页面转场

主 NavHost 通过 `PageNavigationMotion` 统一页面进入、离开与普通返回动画。`pageDestination` 为所有移动中的页面提供独立的不透明底色，避免透明页面在转场时透出上一页内容。集合页、歌单／专辑／歌手详情、搜索结果与设置子页不再单独覆盖动画。

- 默认横向推进：新页面从 End 侧完整进入，旧页面向 Start 侧移动四分之一宽度；返回时反向。使用相同时间与缓动，不叠加整页透明度变化，RTL 随布局方向镜像。
- 推荐、发现、音乐库、设置这四个主目的地之间使用短淡入淡出，不表示进入下一级；主页面与详情之间仍使用推进。
- 外观 → 页面动画提供横向推进、淡入淡出、无动画，以及快速、标准、舒缓。分别保存为 `pageTransitionStyle` 与 `pageTransitionSpeed`，通过现有 DataStore 枚举偏好持久化；主 NavHost 实时订阅，无需重启。
- 快速／标准／舒缓推进时长为 200／300／400ms，淡入淡出为 120／180／240ms。无动画时禁用速度选择，并保留已选速度以便重新开启动画。
- Compose 的系统动画时长缩放继续生效；系统预测性返回手势沿用导航库的交互反馈。这组设置只调整导航页面，不改变播放器展开、封面和歌词动画。

验证覆盖主页面和详情之间的路由分类、禁用动画、非法偏好回退，以及现有集合页返回栈和状态恢复。按协作约定不安装 APK、不进行设备视觉检查。
